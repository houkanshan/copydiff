## HTML Rendering Architecture

This note describes how `copydiff` generates HTML output and where styling logic lives.

### High-level flow

1. Parse diff text into structured files/hunks/lines (`src/diff/parse.ts`).
2. Overlay clone metadata on added lines (`src/overlay.ts`).
3. Render HTML (`src/render/html.ts`) when `--html` is provided in the CLI.

### Core renderer (`src/render/html.ts`)

- **Input:** a list of `FileDiff` objects with hunks and copy overlay metadata.
- **Output:** a complete HTML document with inline CSS, plus unified and
  side-by-side layouts that can be toggled in-page.
- **Per-file language:** each file resolves a language based on filename or extension
  (e.g., `.ts` -> `typescript`). Unknown extensions fall back to `text`.

### Syntax highlighting

- Uses **Shiki v3** via the `codeToHtml` shorthand.
- The renderer calls `codeToHtml` with a joined block of code lines and then
  extracts per-line HTML from Shiki’s `<span class="line">…</span>` output.
- Each diff line is rendered by wrapping the Shiki line content in a custom
  `<span class="line ...">` that carries diff classes and markers.

### Diff styling and markers

- **Line wrapper:** `<span class="line {add|del|context|meta}">`.
- **Marker:** a fixed-width `<span class="marker">` shows the leading `+/-/ `.
- **Line numbers:** old/new line numbers render alongside the marker.
- **Backgrounds:** handled by CSS variables in the `<style>` block.
- **Moved lines:** if ANSI metadata indicates moved/dimmed lines, the renderer
  adds a `moved` class; CSS can dim or remove backgrounds for these lines.
- **Inline edits:** small add/delete pairs receive inline highlights so only
  changed tokens are emphasized; the renderer skips inline highlights when
  ANSI backgrounds or faint styling are present to avoid double-highlighting.

### Copy overlay rendering

- Added lines tagged by the overlay can be marked as copied:
  - Copied additions get a left accent marker.
  - Copy runs show a small marker icon; click to expand a "copied from ..." block with the source snippet when available.
  - Copy edits can include inline highlights against the source line, and these only apply when a normal add/delete inline diff is not already used.
- Pure-copy runs can be collapsed into `<details>` blocks.

### Folding

- Fold segments are computed in `src/overlay.ts` and passed into the HTML
  renderer per hunk.
- The renderer emits `<details class="pure-copy">` sections with a summary line.

### CSS ownership

All HTML styling is in the `<style>` block generated by `buildHtmlHead` in
`src/render/html.ts`. Adjust colors, backgrounds, and text styling there.
